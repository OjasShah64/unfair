🚀 QUICK START
═══════════════════════════════════════════════════════════════════════════════

OPTION 1: Windows User
  1. Double-click: quickstart.bat
  2. Follow on-screen instructions
  3. Load extension in Chrome
  ✨ Done!

OPTION 2: Mac/Linux User
  1. chmod +x quickstart.sh
  2. ./quickstart.sh
  3. Follow on-screen instructions
  ✨ Done!

OPTION 3: Manual Setup
  Backend:
    cd server
    python -m venv venv
    source venv/bin/activate  (Mac/Linux) or venv\Scripts\activate (Windows)
    pip install -r requirements.txt
    python main.py

  Extension:
    1. chrome://extensions/
    2. Developer mode ON
    3. Load unpacked → client/public/

📞 SUPPORT & DEBUGGING
═══════════════════════════════════════════════════════════════════════════════

Content Script Not Capturing?
  • Check DevTools console for [UNFAIR] messages
  • Ensure ChatGPT/Claude tab is active
  • Refresh the page
  • Reload extension (chrome://extensions)

Backend Not Syncing?
  • Verify backend is running: curl http://localhost:5000/api/health
  • Check config.js API_BASE_URL setting
  • Review Network tab in DevTools
  • Check backend logs for errors

Timer Issues?
  • Open DevTools Console
  • Look for any JavaScript errors
  • Reload extension
  • Check that browser hasn't paused the extension

Database Errors?
  • Verify requirements.txt installed: pip list
  • Delete unfair.db and restart backend
  • Check .env file exists and is readable
