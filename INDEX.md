3. Terminal: ./quickstart.sh
4. Follow on-screen instructions
5. Load extension in Chrome when prompted

MANUAL SETUP (5 minutes)
──────────────────────
Backend:
  1. cd server
  2. python -m venv venv
  3. source venv/bin/activate (Mac/Linux) or venv\Scripts\activate (Windows)
  4. pip install -r requirements.txt
  5. python main.py

Extension:
  1. Open chrome://extensions
  2. Enable "Developer mode"
  3. Click "Load unpacked"
  4. Select client/public folder

  🆘 HELP & TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

ISSUE: Extension won't load
  SOLUTION: Check chrome://extensions for error messages
  HELP: See VERIFICATION_CHECKLIST.md → Common Issues

ISSUE: Timer not updating
  SOLUTION: Check browser console for errors (Ctrl+Shift+J)
  HELP: Search for [UNFAIR] logs in console
  HELP: See DEVELOPER_GUIDE.js → Common Issues

ISSUE: Backend not responding
  SOLUTION: Verify server is running: curl http://localhost:5000/api/health
  HELP: See DEVELOPER_GUIDE.js → Backend Debugging

ISSUE: Interactions not capturing
  SOLUTION: Check content script console on ChatGPT/Claude tab
  HELP: Look for [UNFAIR] Content script loaded message
  HELP: See DEVELOPER_GUIDE.js → Content Script Debugging
